# What would Emīls do

A design-taste skill for coding agents: how Emīls Kraucis (product designer at Balsio, Riga) designs, written as about seventy-five rules in the shape when → do → because. Restraint first: remove before adding, quiet the neighbours, take values from the system, make the edge cases part of the screen.

## Install

```
npx skills add EmilsK/what-would-emils-do
```

Add `-g` to install it for all projects, or `-a claude-code` (or another agent) to pick where it goes.

## What it does

- Loads when the agent designs, builds or reviews a screen, page, component, form or line of interface copy.
- `CHECK.md` is thirteen questions to run over the finished thing before calling it done.
- Ask "review this against the taste" and you get what matches, what clashes and the smallest fix. The decision stays with you.

## What it is not

Not a design system or tokens, and not a brand. It is one person's taste, dated and changing; `[his call]` lines are things he said, `[inferred]` lines are an agent's reading of his work. Fork it and replace the lines with your own.
